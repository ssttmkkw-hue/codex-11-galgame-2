# 終電のあと、始発まで。

凌晨 00:30，你在涩谷错过了末班车。距离始发还有 260 分钟。穿过新宿黄金街、秋叶原、浅草的隅田川和东京塔下的坂道，听四位同样滞留在夜里的人讲讲她们的故事。

## 怎么玩

1. 在标题页点 **开始夜行**，读完序章并选一项行动。走路和剧情选项会消耗游戏内的分钟。读对话、看地图和存档时，游戏时钟会停在原处。
2. 在地图上选择地点，查看步行时间和到达时刻，再点 **步行前往**。到达后点 **停留** 推进当地故事。四位女主角各有六幕，一晚的时间最多够和三位初次见面。
3. 在第三幕和女主角约好清晨见面，她就会出现在地图的 **始发安排** 里。可以继续读她的故事，也可以先去别处。选择赴约时，游戏会自动走回约定地点并等到 04:50。请留够返程时间。
4. 完整读完一个结局后，可以在 **回忆画廊** 重读、试听结尾曲。和角色初次见面后，也可以在画廊试换她的表情、试听角色主题。

### 阅读与存档

| 操作 | 方法 |
| --- | --- |
| 推进对话 | 点击或轻触对话框，也可按 `空格` 或 `Enter`。文字还在出现时，第一次操作会补完当前句。 |
| 自动阅读 / 快进 | 点对话下方的按钮，或按 `A` / `S`。两种模式都会在需要选择时停下。 |
| 查看已读内容 | 点 **文本记录** 或按 `L`。 |
| 继续或尝试另一种选项 | 标题页的 **继续夜行** 读取自动存档。**存读档** 有三个手动栏位，适合在关键选项前留档。 |

存档、画廊进度和设置保存在当前浏览器。从标题页开始新的一夜会覆盖自动存档，手动栏位可继续读取。点右上角的音乐按钮静音，在 **设置** 里调节音量、文字速度和自动阅读的停留时间。

### 十个结局

- 四位女主角各有一个始发结局。读到第六幕并接受她的新约定后，**始发安排** 会多一项选择，通向另一段清晨故事。两种赴约方式都可以选。
- 留在当前位置等始发，会看到独自搭车的故事。在东京塔下重画通勤图并留在那里等始发，会看到另一个城市结局。
- 每个结局都有自己的三段式配乐。夜行曲会随时间放轻节奏，角色主题也会随着剧情进展和好感增加新声部。切换街区或场景时，配乐会在小节交界处淡入淡出。

## 本地运行

```sh
npm start
```

打开 <http://localhost:4173/>。本地服务器需要 Python 3。运行 `npm test` 可用 Node.js 检查时间预算、十个结局、旧存档和配乐切换。

## GitHub Pages

在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，发布 `main` 的 `/ (root)` 目录。入口是仓库根目录的 `index.html`。所有资源都使用相对路径，可直接运行在 `/codex-11-galgame-2/` 下。

游戏使用原生 HTML、CSS、JavaScript 和 Web Audio。运行时没有服务端、构建步骤或外部请求。浏览器会在第一次互动后启动音频。素材见 [ASSETS.md](ASSETS.md)。

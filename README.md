# 終電のあと、始発まで。

凌晨 00:30，你在涩谷错过了末班车。距离始发还有 260 分钟。穿过新宿黄金街、秋叶原、浅草的隅田川和东京塔下的坂道，听四位同样滞留在夜里的人讲讲她们的故事。

## 玩法

- **走路和剧情选项消耗游戏内的分钟。** 阅读、存档和看地图不会走时。见完四个人需要超过一晚的时间。
- 在地图上选择目的地，再确认步行。到达后可以停下来读当地的故事，或继续去下一站。
- 和一位女主角约好见面之后，地图会显示她的始发选项。请给返回约定地点留足时间。游戏共有六个结局。
- 打开声音，可以听到五个街区和四位女主角各自的旋律。越接近天亮，音乐越轻。角色好感升高后，旋律会加入新的声部。回忆画廊可播放已解锁的角色旋律和结尾曲。
- 点击对话框继续。空格或回车也可以推进对话。按 `A` 开关自动阅读，`S` 开关快进，`L` 打开文本记录。自动和快进会在选择处停下。
- 本地浏览器保存一个自动存档、三个手动存档，以及设置和画廊进度。从标题开始新一夜会覆盖自动存档。

## 本地运行

```sh
npm start
```

打开 <http://localhost:4173/>。本地服务器需要 Python 3。使用 Node.js 运行 `npm test`，检查时间预算、分支、六个结局和配乐结构。

## GitHub Pages

在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，发布 `main` 的 `/ (root)` 目录。入口是仓库根目录的 `index.html`。所有资源都使用相对路径，可直接运行在 `/codex-11-galgame-2/` 下。

游戏使用原生 HTML、CSS、JavaScript 和 Web Audio。运行时没有服务端、构建步骤或外部请求。浏览器会在第一次互动后启动音频。素材见 [ASSETS.md](ASSETS.md)。
